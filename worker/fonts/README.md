# Fonts

Optional. Put licensed `calibri*.ttf`, `cambria*.ttf` and `consola*.ttf` here (for example from a Windows
install you own) before building the worker image, and the PDF uses them. Without them LibreOffice uses
Carlito and Caladea, which have the same metrics, so pages break the same way; only the code font differs.
The font files are git-ignored.
