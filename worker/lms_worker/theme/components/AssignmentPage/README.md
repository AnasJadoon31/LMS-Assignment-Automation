# AssignmentPage

The first page of an exercise: the header, the numbered banner, the Task and Result box, then the sections that explain the work, with grid figures, drawn figures and data tables, each captioned.

You provide the exercise title and a two- or three-word tag, the question quoted from the sheet, the answer in one sentence with the answer itself bolded, and the sections ("Given Graph", "How It Works", ...). Captions are numbered through the whole report: Figure 1, Table 1, Screenshot 1. The answer row of a table is the one on sky. Every exercise starts on a new page.
