Greedy Best First Search

Greedy Search
TASK
Write a Python program that performs greedy best first search algorithm for the given graph having starting node S and goal node G.
RESULT
The search reaches the goal through S → A → B → F → G

Given Graph

The lab sheet gives only the table of heuristic values and no edges. So I treated the table as a grid, where every cell is connected to the cell above, below, left and right of it (no diagonal moves).

Sh = 3Ah = 5Bh = 1
Dh = 9Eh = 6Fh = 4

Figure 1: Heuristic grid from the lab sheet. Dark cells show the path found by greedy search.

How It Works

Greedy best first search only looks at h(n). At every step it expands the node in the queue with the smallest heuristic value and ignores the cost travelled so far.
