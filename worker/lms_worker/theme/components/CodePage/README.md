# CodePage

The code, the Jupyter Notebook screenshots and the output of an exercise: the file-name bar, the whole program in the theme's code colours, the notebook and each cell framed and captioned, and the last cell after running as the Output.

The code starts on a new page when the exercise's opening leaves room on its first page. The program is real and its output is the real output of running it, never typed. Screenshots come from Jupyter Notebook in a 1180 x 640 window at twice the pixel density; the notebook view appears once, in the first exercise. A program that is not Python shows its output in a code block instead of a screenshot.
