# Figures

How diagrams are drawn in a report, shown here with a route graph: the answer in navy with a gold ring, everything else in sky with navy outlines and grey connectors, values beside the shapes in muted grey.

The same look applies to every diagram a theory or programming question needs: trees, flowcharts, state machines, circuits, block, ER and UML diagrams, and plots. Diagrams are always drawn fresh, never pasted from the sheet, about 5.4 inch wide, centred and captioned "Figure N: ...". A table of values (a heuristic grid) is drawn as a grid figure instead: square cells, navy for the path and sky for the rest.
