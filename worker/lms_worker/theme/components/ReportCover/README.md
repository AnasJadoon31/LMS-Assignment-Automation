# ReportCover

The first page of every report: the logo, the university, campus and department, the navy title band and the details table, inside a navy page border.

You provide the report kind and number ("LAB REPORT 05" or "ASSIGNMENT 02"), the title as on the sheet without its "Lab 5:" prefix, the course code and name, and the date. The student details, the semester and everything else never change. The cover has no header, footer or page number.
